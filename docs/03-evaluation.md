# 效果验证与限制

当前状态：**M1 基础实现和测试已完成；Agent/数据库/真实模型/网页尚未实现或验证。**

## 已完成与未完成

|内容|当前状态|可说明的结论|
|---|---|---|
|需求、架构与契约文档|已编写|存在可供审查的设计|
|目录、链接、Git 忽略规则的准备检查|见 P0-ACCEPTANCE|仅说明交付结构可用|
|确定性业务测试与本地资料集成|开发环境与独立 wheel 环境各 70/70|已测边界的规则、时间、身份、状态转换符合预期|
|SQLite 持久化与并发测试|未实现/未执行|无保存或幂等正确性结论|
|离线 Mock 验收|未实现/未执行|无完整流程结论|
|真实模型路径|待用户配置后实现/运行|无模型决策效果结论|
|元数据与文案审核|规则与码点证据已有 M1 实现和测试|仅合成规则和已测样例，不代表通用审核效果|
|轻量本地网页|设计已补充，待 CLI 核心后实现|无网页运行或交互验证结论|
|工具 Schema、提示、标准规则与样例|设计基线 v1 已收口|仅材料准备，不代表模型协议或运行效果已通过|

## 评估入口

用例、预期、分母和证据要求见 [test-plan](design/test-plan.md)。六个题面必验点均已映射到计划用例；当前不是通过清单。

未来证据目录：

- [输入](../examples/inputs/)：计划保存已执行案例的输入。
- [输出](../examples/outputs/)：计划保存实际结果。
- [Trace](../examples/traces/)：计划保存实际步骤。
- [评估](../examples/evaluation/)：计划保存断言、指标及运行清单。

inputs/outputs/traces 仍无 Agent 实际材料；evaluation/ 已有 M1 实际验证记录，入口为 [M1 验收](M1-ACCEPTANCE.md)和[机器摘要](../examples/evaluation/M1-summary.json)。完整 Agent 用例仍须后续逐项留证。

## 当前不能下的结论

可以声称 M1 的 70 个基础方法在两个环境通过；不能声称已实现 ReAct、数据库保存/防重复有效、所有 READY 草稿无冲突或真实模型准确率。设计中的 JSON 投影仍是预期。

## 已知边界

合成元数据与文案规则不能证明真实视频审核效果；本地草稿占用不能证明平台时段锁定；本地操作者标签不构成多人认证；固定偏移日期不提供 DST 推断。真实模型未接入，完整考核尚未满足。

# 效果验证与限制

当前 **M2 工具与真实 SQLite 验证完成**；尚无 Agent 决策循环、业务 CLI、真实模型或网页。

|内容|实际结果|可说明的结论|
|---|---|---|
|M1 规则、时间、身份、纯草稿状态|70 个历史基础测试通过|确定性基础符合已测预期|
|M2 工具、SQLite、确认、故障及并发|43 个新增方法；合计 113 个在开发与独立 wheel 环境均通过|已测本地事务和保护行为符合预期|
|M2 七组实际工具案例|正常/缺失/风险/冲突/重复/保存失败/确认全部断言通过|业务工具闭环可运行；驱动方式为 manual_tools|
|编译、依赖、独立安装来源|实际日志和哈希已保存|包可安装，非仅从 editable 源码运行|
|Mock Agent / 真实模型 ReAct|未实现/未执行|无模型动态决策效果结论|
|本地网页与媒体扩展|仅设计|无交互或视觉审核验证结论|

逐项预期、实际结果、命令、限制和代码入口见 [M2 验收](M2-ACCEPTANCE.md)。机器证据：[测试摘要](../examples/evaluation/M2-summary.json)、[七组案例清单](../examples/evaluation/M2-cases.json)、[开发测试日志](../examples/evaluation/M2-development-tests.txt)、[独立 wheel 日志](../examples/evaluation/M2-clean_wheel-tests.txt)。该清单逐一引用 examples/inputs、outputs、traces 的实际文件和校验值。

113 为 unittest 方法数量，subTest 输入不额外计数，两个环境不计成 226 个独立用例。M1 报告保留为历史事实，不要求其源码哈希匹配后续版本。

本轮实际验证保存中途故障回滚、提交后回执丢失查证、查证失败 UNKNOWN、旧成功不能掩盖新失败、同请求重复和并发、跨请求争用、确认版本与资料失效、补查及来源矛盾。查到旧草稿不能代替本次操作回执证明写入成功。

本轮修正时段版本未涵盖本地占用、审核观察标记未比较当前快照两个问题，并保留回归断言；未发现需删除失败输入才能通过的情况。

已知边界：故障注入不等于真实断电恢复；双线程并发不等于多进程负载测试；合成规则不证明通用内容安全或视觉审核能力；本地 READY 不代表平台锁时段；操作者标签不是多人认证；固定偏移时间不推断 DST。

完整考核仍须 M3 预算及循环、M4 至少两条真实模型动态路径及最终 GitHub 交付。7 组手动工具记录不能替代模型验收。

## 推进约束

- 不按三小时截断，以核心正确性和证据完整性为优先。
- 每阶段完成后更新 STATUS、评估记录与 AI 使用记录；未完成项继续保留。
- 用户在设计完成后要求下一步，已据此完成 M1/M2/M3；后续用户提供 DeepSeek 密钥，已完成 M4，不重复索取密钥。
- 用户已确认元数据与文案审核、图片/视频只预留扩展，以及 CLI 核心后补轻量本地网页。当前 CLI、离线 Mock、DeepSeek 适配器与本地网页均有实际代码与验证。
- M5 以 CLI 核心通过为前提；M4 真实模型若暂缺配置，可独立推进不依赖配置的设计/工作，但最终交付仍需真实决策证据。
- 本地网页不意味着线上部署；首版不创建托管站点或引入多人账号。
- 不为通过测试删掉失败样本；修复后保留原失败与回归依据。

# 合成资料目录（M1）

数据实体与约束见 [数据契约](../docs/design/contracts.md)。

- `catalog/`：合成素材与带来源的补充元数据。
- `rules/`：带 ID 和版本的示例审核规则。
- `schedules/`：合成既有排期与候选时段。

实现阶段按验收用例生成最小可核对资料，明确标注合成。不得纳入真实内容、隐私或前雇主数据。JSON 导入数据库后才成为运行事实源；直接改文件不自动改变运行状态。

M1 已从设计基线落下 5 份合成素材、5 条规则、3 个候选时段、空补充/占用集合，以及 requests/normal.json 的完整请求。当前只有校验和加载，尚未导入数据库，也不是实际模型结果。
